平台在做什么

同一份模型、同一份调用代码，通过 EdgeRuntime(backend=…) 在 ONNX Runtime CPU 与（模拟/真实）NPU 之间切换； 上层业务代码不需要知道底下跑在哪块硬件上。
命令行等价用法：python examples/demo.py · python tests/test_backends.py · python -m uvicorn webapp.server:app --port 8000
接入真实 NPU：在 runtime/backend/ 新增一个继承 BaseBackend 的类并加 @register_backend("xxx") 即可出现在上方后端列表里。
